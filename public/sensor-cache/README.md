# Sensor Cache

This directory contains pre-generated static JSON files for instant sensor loading.

Generated by: `npm run generate-cache`

Files:
- `airTemperature.json`
- `relativeHumidity.json`
- `atmosphericPressure.json`
- `pm25.json`
- `pm10.json`
- `no2.json`

These files should be regenerated periodically (daily/weekly) when new sensors are added.
